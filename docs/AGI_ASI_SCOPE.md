# AUREON Cognitive Roadmap: AGI-Agent Research Architecture

## Reality boundary

AUREON is an engineering project for increasingly general autonomous problem-solving. It does not claim to be AGI or ASI.

"AGI" and "ASI" are treated here as research targets requiring measurable capabilities, not marketing labels.

## Capability ladder

### Level 1 — Tool agent
Executes bounded workflows with tools.

### Level 2 — Generalist agent runtime
Handles unfamiliar tasks through decomposition, planning, execution and verification.

### Level 3 — Adaptive agent
Learns reusable strategies from successful and failed missions.

### Level 4 — General capability research target
Transfers abstractions across substantially different domains and improves performance without hand-written workflows for each task.

### Level 5 — ASI research target
Would require demonstrated performance vastly beyond the best available human capability across broad domains. AUREON must not claim this without extraordinary evidence.

## Required cognitive subsystems

- working memory
- durable episodic memory
- semantic knowledge store
- skill library
- hypothesis generation
- experiment selection
- planning
- reflection
- adversarial self-critique
- uncertainty estimation
- transfer evaluation
- continuous benchmark evaluation

## Governing rule

Capability claims must be backed by reproducible benchmark evidence.
